# Engineering Journal

Add the current journal as `engineering-journal.pdf` and optionally keep dated Markdown entries in this directory.

Each entry should record:

- Date and team members present
- Goal or problem
- Design or code change
- Reason for the decision
- Test method and conditions
- Quantitative result where possible
- Photographs, screenshots, or graphs
- What failed or remained uncertain
- Next action

The journal should tell the story of the engineering process, including unsuccessful attempts and the evidence that led to each important change.
